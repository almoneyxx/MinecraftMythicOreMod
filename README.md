## Minecraft Mythic Ore Mod
A Minecraft Forge mod that introduces new ores, materials, weapons and armour to the game.

### Features
- Twilight Ore and Luro Ore
- Naturally generated custom ores
- Raw materials and ingots
- Smelting and blasting recipes
- Twilight Sword
- Full Luro armour set
- Custom crafting recipes, models and textures

### Requirements
- Minecraft 1.21
- Minecraft Forge 51.0.33
- Java 21

### Building the Mod
- Download or clone this repository.
- Open the project folder in IntelliJ IDEA or another Java IDE.
- Build the project using:
  
### Windows

    gradlew.bat build

### Linux or macOS

    bash gradlew build

4. The completed `.jar` file will be created inside the `build/libs` folder.

## Installation

1. Install Minecraft Forge 51.0.33 for Minecraft 1.21.
2. Place the mod’s `.jar` file inside your Minecraft `mods` folder.
3. Launch Minecraft using the Forge profile.
